# Coffee-shop-sales
# ☕ Coffee Sales Dashboard | Excel

An interactive Excel dashboard designed to analyze coffee sales performance and provide a clear overview of sales, transactions, products, payment methods, and locations.

## 📊 Dashboard

The dashboard provides insights into:

* 💰 Total Sales
* 🧾 Total Transactions
* 📦 Total Quantity Sold
* 💵 Average Transaction Value
* 📈 Monthly Sales Trends
* ☕ Sales by Product
* 💳 Sales by Payment Method
* 📍 Sales by Location

## 🛠️ Tools Used

* **Microsoft Excel**
* Excel Formulas
* PivotTables
* PivotCharts
* Data Cleaning
* Data Visualization
* Slicers

## 🎯 Project Objective

The objective of this project is to transform raw coffee sales data into an interactive Excel dashboard that makes it easy to understand sales performance and identify important business trends.

## 🔍 Key Features

* Interactive dashboard
* Sales and transaction KPIs
* Monthly sales analysis
* Product-wise sales analysis
* Payment method analysis
* Location-wise sales analysis
* Interactive slicers and filters
* Clean and user-friendly dashboard design
